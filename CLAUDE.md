# Roses N Chic

Luxury women's clothing store. Handloom pure cotton and viscose rayon. Atelier in Chennai, India.

## Brand rules
- Style: bright, radiant, feminine, romantic.
- Colors: soft blush pink, champagne gold, ivory. Rose-gold gradient on the logo.
- Fonts: Cormorant Garamond (headings), Montserrat (text).
- Do not use dark, rugged, or edgy styles.

## Tech rules
- Next.js (App Router), TypeScript, Tailwind CSS, GSAP, Lenis, Supabase.
- Payments: Razorpay and Stripe. The server sets all prices.
- Never put secret keys in browser code.
- RLS must be on for every table.
- Check all input with Zod.

## Work rules
- Read `plan.md` first. Do one phase at a time.
- The hero section is already built in `hero/`. Read `hero/README.md` before you touch it.
- Read the matching skill before you start a task.
- Run tests before you say a task is done.
- Do not change files outside the task.
- At the end of each phase, update `PROGRESS.md` and commit to Git.
